57// cop/idx need to be real preprocessor tokens (not just compile-time-
58// constant expressions) so # can stringize them directly into the
59// mnemonic/register text - real GCC could fold get_mips_cop_reg's old
60// "i"-constrained function-parameter version lazily, after always_inline
61// substituted each call site's constant arguments, regardless of the
62// caller's own -O level. Clang instead validates "i" constraints during
63// Sema, before any constant-folding pass runs, so a caller built at -O0
64// (e.g. sdk-core's eedebug package) hit "invalid operand for inline asm
65// constraint 'i'" even though cop/idx are always real compile-time
66// constants at every call site. Macros sidestep the whole question -
67// this is why COP0_REG_* above became #defines instead of an enum, so
68// they're valid ## arguments here.
69// COP0_REG_* are themselves macros, so #cop/#idx need the classic
70// two-layer stringize indirection (MIPSCOPACCESS_STR/_XSTR) - a bare
71// "#idx" would stringize the literal argument text ("COP0_REG_PRId"),
72// not its expansion ("15"); routing through one more macro layer forces
73// idx to expand first.
74#define MIPSCOPACCESS_STR(x) #x
75#define MIPSCOPACCESS_XSTR(x) MIPSCOPACCESS_STR(x)
