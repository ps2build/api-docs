Detailed Description

Regression tests

Small self-checking EE programs. Each prints <name>: PASS or <name>: FAIL ... through kputs, and run.sh builds it with ps2build, runs it headless in PCSX2 and reports the result.

tests/run.sh # every test, GCC
tests/run.sh --llvm # every test, LLVM
tests/run.sh cxx-iostream # one test

The runner is a bash script, so run it on Linux (or any system with bash); the Windows install has no bash.

Set PS2BUILD and PCSX2 if the tools are not on PATH; TIMEOUT (seconds, default 40) is how long to wait for each result.

Each test directory has one ps2.yaml, built with --toolchain gcc or --toolchain llvm. A gcc.skip or llvm.skip file marks a test as not supported by that toolchain; its first line is printed as the reason.

GCC against LLVM

tests/diff.sh builds the programs in tests/diff with both toolchains at -O0, -O1, -O2, -O3 and -Os, runs them in PCSX2 and compares their <name> <hash> lines.

Program Covers
kernels 94 small float and integer kernels, loops and conversions
libm The single-precision libm functions
fp-compare Comparisons, min, max, clamp, sqrt and abs over NaN, infinities, signed zeros and denormals

A difference listed in <program>/expected (any level) or <program>/expected.<level> is accepted, with the reason in a comment. Any other difference fails. LLVM's results are identical at every level; the accepted differences are GCC calling the library fmaxf, fminf and sqrtf at -O0 and -Os, and the decimal float literal rounding in libm.

tests/gate.sh runs everything: both toolchains' tests and the comparisons.

Benchmarks

tests/bench.sh compares speed and function size of GCC and LLVM builds of a set of EE kernels; results and exceptions are in tests/bench/README.md.

Bus errors (IBE, DBE) have no test: user mode cannot reach kseg, unmapped kuseg addresses raise a TLB miss instead, and reads of EE register-space holes stall the bus without raising an exception. The crash screen still decodes them if a kernel-mode caller triggers one.
